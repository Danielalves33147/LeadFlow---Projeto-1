# API REST

Base: `/api/v1`

Principais recursos: `/auth`, `/dashboard`, `/leads`, `/interactions`, `/tasks`, `/branches`, `/users`, `/score-rules`, `/ranking/branches`, `/notifications`, `/settings`.

A documentação executável é exposta em `/swagger-ui` e `/v3/api-docs`. O arquivo `docs/openapi/leadflow-api.yaml` registra o contrato essencial para integração e pode ser expandido a partir do endpoint OpenAPI do SpringDoc.
